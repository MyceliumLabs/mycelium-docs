# Mycelium Auris Testnet Faucet

The Mycelium Auris testnet (Chain ID: 46969) provides a faucet for developers to obtain test tokens (ECO) for development and testing purposes.

## Chain Information

- **Network Name**: Mycelium Auris
- **Chain ID**: 46969
- **Native Token**: ECO

## Using the Faucet

To get test tokens for development:

1. Visit the [Mycelium Auris Faucet](https://thirdweb.com/mycelium-auris)
2. Connect your wallet
3. Enter your wallet address
4. Request test tokens

You can request test tokens once every 24 hours. Each request will provide you with enough ECO tokens to start developing and testing your applications.
